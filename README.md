# XKCD Now Clock

PoC: A pure javascript, client side version of [http://xkcd.com/now/](http://xkcd.com/now), with ability to permalink fixed time/date.

Forked from https://github.com/RodEsp/xkcd-now-clock which was inspired by this [thread](https://news.ycombinator.com/item?id=7384025) on hacker news and this [project](https://github.com/meandavejustice/xkcd-now) by Dave Justice.

I hoped to use it to send cross-timezone meeting URLs, but that'd NOT work: I learnt that Randall cleverly distorted the labels and/or map to account for time zones & DST when he first published it, but it's not getting updated.  
=> Try https://world-time-sync.com/, https://zoneing.biterdevs.com/planner, https://everytimezone.com/.
