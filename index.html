XKCD Now (or should I say "then"?) Clock

This is a pure javascript, client side version of http://xkcd.com/now/.
Forked by cben for permalinkable fixed time, from RodEsp's real-time version, inspired by this thread on hacker news and this project by Dave Justice.
You can checkout the source here.

DISCLAIMER:
The clock uses UTC and the map's orientation is based on the Greenwich Meridian (roughly England). Therefore England's orientation will always show the correct time but due to scaling issues and things like Daylight Saving time it WILL BE OFF for other locations.

As Explain XKCD says, Randall's original map is intentionally distorted to account for time zones and DST as of Feb 2014. Brilliant! But it has not been maintained in sync with winters/summers and political changes since, so is NOT accurate now.
